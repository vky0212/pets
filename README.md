# pets

## 小紅巫

- [Windows 獨立桌面寵物最新版](https://github.com/vky0212/pets/releases/latest/download/LittleRedWitch-win-x64.zip)：支援 25%–140% 共八種尺寸、紅色巫婆帽 icon，以及 GitHub Releases 自動更新；解壓後執行 `LittleRedWitch.exe`，不需要 Codex。
- [Codex Q 版寵物套件](redhood-witch-doll-chibi-install.zip)：供 Codex 自訂寵物安裝使用。
- [巫婆帽 Icon Pack](little-red-witch-hat-icon-pack.zip)：包含 Windows ICO、透明母版與 12 種 PNG 尺寸。
- [Icon 尺寸預覽](little-red-witch-hat-icon-preview.png)

獨立版支援桌面漫遊、滑鼠拖曳、雙擊揮手、看向游標、尺寸切換、永遠置頂及開機自動啟動。

從 v1.2.0 起，客戶端每 24 小時最多檢查一次正式 Release，也可從右鍵選單手動檢查。更新套件會先驗證 GitHub 提供的 SHA-256 digest，再由獨立 Updater 備份、替換並重新啟動程式。
