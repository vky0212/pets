## 小紅巫

- [Windows 獨立桌面寵物 v3](little-red-witch-standalone-windows-x64-v3.zip)：支援 25%–140% 共八種尺寸，並使用紅色巫婆帽 icon；解壓後執行 `LittleRedWitch.exe`，不需要 Codex。
- [Codex Q 版寵物套件](redhood-witch-doll-chibi-install.zip)：供 Codex 自訂寵物安裝使用。
- [巫婆帽 Icon Pack](little-red-witch-hat-icon-pack.zip)：包含 Windows ICO、透明母版與 12 種 PNG 尺寸。
- [Icon 尺寸預覽](little-red-witch-hat-icon-preview.png)

獨立版支援桌面漫遊、滑鼠拖曳、雙擊揮手、看向游標、尺寸切換、永遠置頂及開機自動啟動。
