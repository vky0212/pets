# 小紅巫桌面寵物 1.2

這是獨立於 Codex 的 Windows 桌面寵物。程式已將 Q 版小紅巫的動畫素材內嵌在 EXE 中，不需要另外安裝素材。

## 使用方式

1. 執行 `LittleRedWitch.exe`。
2. 用滑鼠左鍵拖曳小紅巫。
3. 雙擊小紅巫，她會揮手。
4. 在小紅巫身上按右鍵，可暫停漫遊、跳躍、調整尺寸、切換永遠置頂、設定開機自動啟動或關閉程式。

尺寸共有八檔：25%、35%、50%、65%、75%、90%、115%、140%。最小的「口袋」尺寸約為 48×52 px，預設尺寸維持 90%。

## 自動更新

- 程式每 24 小時最多向 `vky0212/pets` 的 GitHub Releases 檢查一次正式版本。
- 右鍵選單可手動選擇「檢查更新」，也能取消「自動檢查更新」。
- 發現新版時會先詢問；選擇更新後才會下載。
- 更新套件必須通過 GitHub Release 的 SHA-256 digest 驗證。
- `LittleRedWitch.Updater.exe` 會在小紅巫退出後替換檔案，失敗時從 `.update-backups` 還原。

請讓 `LittleRedWitch.exe` 與 `LittleRedWitch.Updater.exe` 保持在同一個可寫入資料夾，並先完整解壓 ZIP 再執行。

小紅巫待機時會看向附近的滑鼠游標，也會在螢幕底部散步。

若要使用「開機自動啟動」，請先把 EXE 放到不會再移動的資料夾，再從右鍵選單啟用。

## 系統需求

- Windows 10 或 Windows 11
- 一般使用不需要系統管理員權限
- 不需要 Codex

## Windows 安全提示

這是未經商店或商業憑證簽署的自製程式。Windows 第一次執行時可能顯示 SmartScreen 提示；確認檔案來自你自己的 GitHub repository 後，可選擇「其他資訊」再執行。

## 關閉與移除

在小紅巫身上按右鍵並選擇「關閉小紅巫」。若曾啟用開機自動啟動，請先在選單取消勾選，再刪除 EXE。
